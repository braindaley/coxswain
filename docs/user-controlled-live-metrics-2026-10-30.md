# User-controlled metric blocks

Metric blocks belong to the user's selected layout. Goals no longer insert, replace, relabel, color, or substitute variance values into those blocks. The picker saves only the chosen six bindings. Selected blocks show actual measurements; heart-rate zone backgrounds retain their separately requested behavior. Live split keeps its recent display average and work average split remains a work-only cumulative average.

Target instructions and faster/slower/above/below feedback now live in the bottom coaching section. This includes the actual current target metric, even when the user has not chosen that metric as a block. The short feedback average and exact prescribed split are retained. Regular program targets also use this section. Recorded-race and fixed-pace rail comparisons remain visible separately.

This supersedes the earlier automatic goal-metric overlay. It does not guess which metric an older app version may have saved over a user's selection; an already changed saved slot can be selected again through Edit. New goals do not modify the layout.

Regression checks cover layouts with and without split, preservation of selected speed and stroke-rate blocks, neutral block colors during faster/slower readings, unchanged stored bindings, and explicit directional feedback below the grid.
