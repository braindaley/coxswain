# Coxswain product design

This repository preserves the Coxswain Android companion-app design work.

## Primary artifacts

- `outputs/Coxswain_Interactive_Screen_Canvas.html` — standalone interactive screen canvas
- `outputs/Coxswain_Product_Design_Spec.docx` — current product design specification
- `outputs/Coxswain_Live_Row_Free.html` — interactive Live Row component and target states
- `outputs/Coxswain_Workout_Setup.html` — shared quick-workout and program setup component
- `outputs/Coxswain_Programs.html` — My Programs and Workout Library prototype
- `outputs/Coxswain_Program_Detail.html` — immutable saved-program detail prototype

The `work/` directory contains the atlas screenshots, approved source images, and Python scripts used to rebuild and update the artifacts. Temporary DOCX render directories are intentionally ignored.

Open the interactive canvas directly in a browser; it has no build or server dependency.
