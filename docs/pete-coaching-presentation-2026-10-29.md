# Pete's Plan coaching presentation

Briefings now distinguish split targets, stroke-rate targets/caps, advisory pacing references, missing references, and recorded races. Split targets show the exact /500 m value, source workout/date, and whether that target matches or adjusts the source's work-only average split. Targets limited to opening work intervals state that scope. Only recorded replay uses the “Race previous row” start label.

Live status keeps a short metric-specific coaching instruction visible. Rate goals distinguish a cap from an exact rate. Advisory references are labeled as references. Opening-interval split targets stop being prescribed when those intervals end. Rest retains its recovery/next-interval presentation. True races retain the large ahead/behind readout and name the previous row's date in the legend; fixed split targets retain their separate target-pace rail.

The underlying coaching rules, target calculations, and race scoring are unchanged. Tests cover every goal kind, target adjustments and source labels, phased targets, race metric wording, and live UI transitions through recovery.
